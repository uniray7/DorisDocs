# 如何申請 <服務名稱>

> 對外文件，讀者是不熟悉 Doris 內部實作的其他部門使用者。避免內部術語，只講使用者需要知道的行為。

## 適用對象
這個服務適合什麼情境／不適合什麼情境（例如：適合 OLAP 分析查詢，不適合當交易型資料庫）。

## 申請前準備
- 需要準備的資訊（預估資料量、QPS、使用情境說明、成本歸屬部門等）

## 申請流程
1. 提出申請（管道：表單/工單系統連結）
2. 審核（審核單位、預期審核時間）
3. 核准後佈建（預期等待時間）
4. 取得存取憑證/連線資訊

## 審核標準
- 列出審核會看哪些條件（例如：資料是否含敏感資訊需額外簽核、資源規模是否超過某門檻需要主管核准）
